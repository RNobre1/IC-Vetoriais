- ADR: [[../decisões/2026-05-19-cronograma-canonico-relatorio]]. Commit `f30ff6a`.

### 2. Cenário B — decisões metodológicas (ADR)
- **Predicado:** atributo numérico `seletor` uniforme determinístico em [0,1); filtro `seletor < p` (p ∈ {0.01, 0.10, 0.50, 1.0}). p=1.0 = sem filtro (âncora vs Cenário A).
- **Ground truth:** recall@K contra o top-K exato **dentro do subconjunto filtrado** (1 GT por seletividade), não o GT global do A.
- ADR: [[../decisões/2026-05-19-cenario-b-seletividade-gt-filtrado]]. Commit `b21d8fa`.

### 3. `top_k_exato_filtrado` (GT do Cenário B) — TDD
- `ground_truth/exact_search.py`: `top_k_exato_filtrado(base, queries, *, seletor, p, k)` — máscara `seletor < p`, FAISS no subconjunto, ids remapeados para os originais (0..N-1). `k` clampado quando `|subconjunto| < k`. p=1.0 ≡ `top_k_exato` (testado como âncora).
- `tests/unit/test_ground_truth.py`: +10 testes (shape/dtype, só ids que passam, top-1 remapeado, p=1 ≡ global, clamp, determinismo, 4 bordas). **22/22 verde.** Commit `9fad3cf`.

### 4. Seeders gravam `seletor` — TDD (integração)
- `pgvector_seeder`: coluna `seletor real` (nullable). `weaviate_seeder`: propriedade `seletor` (`DataType.NUMBER`). `qdrant_seeder`: payload já era schemaless (gravava automático) — adicionado **índice de payload** `seletor` (FLOAT) condicional (só quando o metadata tem `seletor`), para o filtered-ANN do Qdrant ser comparável aos demais. Cenário A (`metadata=None`/sem a chave) **intacto** — recursos byte-idênticos.
- `tests/integration/test_seeders.py`: +3 testes (1 por SGBD) provando `seletor < 0.1` ⇒ exatamente 100/1000 itens. **9/9 verde** (regressão do A preservada). Commit a seguir.
